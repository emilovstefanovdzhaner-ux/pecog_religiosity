# pecog_religiosity
This file is created for project on religiostiy by Dzhaner Stefanov. You can find PsychoPy files and R scripts for data analysis.  

In the experiment, it has 4 blocks, each one includes 20 trials (16 trials + catch trials). Trials have different SOA levels (400-600-800-1000 ms) and target posiiton (up or down). 

"sequence.xlsx" is created for blocks, while "step1.xlsx" is created for one block that includes 20 trials.

The total duration of the experiment takes approximately 20 minutes. 

Screenshot file in the "visual" is serving as a regulator between trials. It helps to create a gap for 1 second between trials. 

The experiment is designed to run locally, so users should be aware code component is not tested in online format. 

You should keep all files in the same place to run the program accurately, except one file: data_cleaning_R.

This file is created for data analysis of output files from PsychoPy. It is an automation system.

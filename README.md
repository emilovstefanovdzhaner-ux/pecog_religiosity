# pecog_religiosity

This file is created for the project on religiostiy by Dzhaner Stefanov. You can find PsychoPy files and R scripts for data analysis.  

In the visual file, you can reach a screenshot and 2 videos. The screenshot is embedded for a gap between trails for 1 second. Videos are generated by Gemini, and prompts are "You should only change the mouth movements. Keep the same perspective. The sentence that this man should say is that "Throughout history, artists and writers have used their creative talents to depict God in ways that resonate with the public. " Can you generate a video? It should include a kind of religious music in the background. The ratio should be 16:9" and "You should only change the mouth movements. Keep the same perspective. The sentence that this man should say is that Religious scholars frequently analyze how the concept of devil has evolved across different centuries. "Can you generate a video?" It should include a kind of religious music in the background. Ratio should be 16:9". 

These muted visual content's voice files are located in the "voice" file. These sound files were extracted with Riverside, and the onset timing of cues (devil and God) was detected via Praat manually. According to onset timing, it is 4.694 for the word "devil's timing," while it is 6.27 for the word "God's timing." In the XP, 4 different SOA levels are used. These are 400, 600, 800, and 1000 ms. These milliseconds are added to the onset timing of cues. Eventually, the XP has 5.094, 5.294, 5.494, and 5.694 values for cue Devil, respectively (image 1). It is 6.67, 6.87, 7.07, 7.27 for cue God, respectively (image 2).

For loops, 2 different Excel files were created. These are step 1.xlsx and sequence.xlsx. Step1.xlsx is created for all trials (16 trials + catch trials). On the other hand, sequnece.xlsx was created for blocks that are 4. 

You can find these columns: congruency_last, videosource_last, context_last, word_last, Circle_y_last, circle_start_last, SOA_last, circle_opacity_last, duration_last, and voice in step1.xlsx. Please do not make any changes to the names of the columns. It undoubtedly will deficit the actual working style of the XP. The XP was designed to read exactly these named columns. If it might change, the XP won't find and read the files and other information. 

The XP has only two target locations: up and down. According to that, God is consistent with up (0.4), while Devil is consistent with down target (-0.4) on the y-axis, vertically. These are corresponding to "congruency effect," and all trials are congruent except catch trials (blanks). Look at image 4:

The experiment is designed to run locally, so users should be aware the code component (which regulates the synchrony between sound and response timing) is not tested in online format. 

You should keep all files in the same place to run the program accurately, except one file: data_cleaning_R.

This file is created for data analysis of output files from PsychoPy. It is an automation system. It extracts these columns: "participant","trial_number", "congruency_last", "videosource_last","context_last", "word_last", "Circle_y_last", "SOA_last", "circle_start_last", "reaction_time". Eventually, it calculates the adjusted reaction time that corresponds to timing different between the onset timing of the target and the timing of pressing the SPACEBAR.
